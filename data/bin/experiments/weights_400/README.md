추출일: 2026-10-23. 원본은 `data/processed/fin/places.csv`의 동백전 명부 등재 식당·카페입니다. 중복 ID 없는 비복원 층화 추출이며 리뷰·평점·Google 매칭·도보시간은 추출 기준과 엑셀 컬럼에 넣지 않았습니다.

| 대청동 | 31 | 22 | 53 |

대청동은 보유 대상 전부를 포함했습니다. 동별 25%는 확보량 부족으로 적용하지 않았습니다. 나머지 세 동을 115~116곳으로 배정했습니다. 각 업종×동의 ID 정렬 목록에서 Python `random.Random('20261023:sample400:행정동:카테고리명')`으로 `sample`했습니다. 카테고리명은 원본의 식당/카페·디저트입니다.

엑셀 산출물 `동백전_MVP_식당카페_표본400.xlsx`는 추출 요약과 필터 가능한 장소 목록 두 시트입니다. 대용량·바이너리 산출물은 로컬 별도 제공일 수 있어 GitHub에 항상 포함된다고 가정하지 않습니다. 운영 추천 CSV는 변경하지 않았습니다.

이 표본은 서비스에 이미 포함된 식당·카페에 대한 조사 표본입니다. 동백전 전체 가맹점의 단순무작위 표본이 아니며, 추후 매칭률 집계 시 모집단·동별 추출률 차이를 구분해야 합니다.
