기준: 2026-10-23. **운영 추천에는 적용하지 않은 실험**입니다. 현재 서비스는 이동 조건과 상위 노출 순환을 사용합니다. [현재 알고리즘](../../../docs/ROUTE_ALGORITHM.md)과 혼동하지 마세요.

## 표본과 한계

최초 40곳 배분은 식당 17·카페·디저트 17·관광명소 3·쇼핑 3입니다. 업종별로 행정동을 순환 추출하고 이후 사용자 요청으로 일부 장소를 같은 업종·행정동의 다른 장소로 교체했습니다. 검색·평점 존재·도보 조건을 확인한 교체가 포함돼 있으므로 전체 Google 확보율을 추정할 무작위 표본이 아닙니다.

최초 식당·카페는 각각 광복동 5곳, 남포동·부평동·대청동 4곳입니다. 관광명소·쇼핑 각 3곳은 계산 점검용이며 모집단의 추천 품질을 추정하지 않습니다. 출발지는 카카오로 확인한 남포역이고 도보시간은 TMAP 예상값입니다. 이 실험은 출발지 도보 20분을 초과하면 점수 계산에서 제외하는 별도 규칙을 유지합니다.

## 실행

```powershell
python scripts/weight_experiment.py check
python scripts/weight_experiment.py score
python scripts/google_weight_preview.py
```

`prepare`는 최초 추출 규칙으로 다시 쓰므로 교체한 현재 표본에는 실행하지 않습니다. `score`는 저장 가능한 평점·양의 정수 리뷰 수·출처가 있는 행만 계산합니다. Google 미리보기는 저장한 place ID로 재조회하고, 미연결은 이름 유사도 0.9·좌표 200m 이내의 유일 후보를 찾습니다. 자동 기준이 동일 장소를 보증하지는 않습니다.

Google 평점·리뷰 수는 미리보기 실행 중에만 사용하며 CSV에 저장하지 않습니다. place ID와 평점·리뷰의 저장 조건은 다릅니다. 공급자 정책: https://developers.google.com/maps/documentation/places/web-service/policies

## 당시 계산안

- B = (nR + 20C)/(n+20). R은 가게 평점, n은 같은 공급자의 리뷰 수, C는 카테고리 표본 평균입니다.
- Q = (B−1)/4, D = max(0, 1−출발지 도보분/20).
- 식당 = 0.75Q + 0.25D, 카페 = 0.70Q + 0.30D, 관광명소·쇼핑 = Q.

보정 강도 20과 비중은 검증된 최적값이 아닙니다. 평점이 확보된 소수 표본 평균을 C로 쓰면 불안정하며 리뷰 없는 가게의 가치를 판단하지 못합니다. 출발지 거리 점수는 장소 간 전체 코스 효율을 보장하지 않습니다. 리뷰 수를 별도 점수로 다시 더하거나 Google 평점에 네이버 리뷰 수를 넣지 않습니다.
