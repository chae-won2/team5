# GIS 자료와 작업 시점

기준: 2026-10-23 문서 정리. QGIS 프로젝트 `MVP_clean_20261021_143448.qgz`는 이 폴더 전체와 공유하며 점·면 데이터는 상대경로를 사용합니다.

| 위치 | 역할 |
|---|---|
| `mvp/` | 남포·광복·부평·대청 행정동의 가맹점 작업 자료. 최신 표 작업은 `mvp_merchants.csv` 확인 |
| `review/` | 동일 가게·업종 판정 검토표와 후보 |
| `boundaries/` | 행정동·전통시장 상권영역과 원천 설명 |
| `full_busan/` | 전체 가맹점 조사 당시 스냅샷 |
| `qa_20261022/` | 2026-10-22 집계 대조·표본 추출 기록 |
| `file_manifest.json` | 복사 당시 출처·용량·해시 |

QGIS의 기존 GPKG와 후속 매칭한 CSV는 작업 시점이 다를 수 있습니다. 프로젝트 이름이나 과거 조사 문서의 ‘최신’이라는 표현을 현재 서비스 데이터로 해석하지 마세요. 운영 추천 입력은 [../fin/places.csv](../fin/places.csv), 계약은 [장소 명세](../../../docs/PLACES_SCHEMA.md)입니다.

시장 안팎은 상권영역과 가맹점 좌표의 공간 관계입니다. 법적 시장 소속·층별 위치·현재 영업을 보증하지 않으며 시장 안 가게의 업종을 시장으로 바꾸지 않습니다. 개인택시 제외·복구용 파일과 전체 원본은 개별 산출물의 역할을 확인한 뒤 사용합니다.

배경지도는 QGIS 플러그인·인터넷·공급자 설정에 따라 달라질 수 있습니다. 배경지도가 없어도 로컬 점·면은 열 수 있습니다. 중복 CSV·GeoJSON 정리 이력 때문에 과거 파일명이 일부 존재하지 않을 수 있으며, 전체 조사 표는 보관된 GPKG에서 내보낼 수 있습니다. GIS 원본을 자동 덮어쓰거나 삭제하는 재생성은 수행하지 않습니다.
