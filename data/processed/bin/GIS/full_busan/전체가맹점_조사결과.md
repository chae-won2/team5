관광대상외 업종도 업종 근거가 연결된 데이터이므로 미매칭과 구분해야 한다.
검토 4,427건은 출처 간 충돌·세부업종 불명확 등을 포함하며 확정 분류가 아니다.
식당·카페·쇼핑 수는 부산 전체 기준이며 홈페이지 원도심 추천 후보 수와 다르다.
시장 자체와 관광명소는 별도 출처이므로 이 가맹점 전체 조사에 새 장소로 추가하지 않았다.

## 시장 경계

시장 안 3,068건 / 시장 밖 155,647건. 시장 197개 상권영역과 원본 가맹점 좌표로 판정했다.
시장 안 업종을 시장으로 덮어쓰지 않고 in_market, market_ids, market_names 필드로 분리했다.
상권영역은 법적 시장 소속 명부가 아니며, 지하/지상 층 구분과 지오코딩 오차는 반영하지 못한다.

## 데이터 품질

- ID 중복: 0건. 상호·주소 완전 동일 중복: 0그룹.
- 상호 누락: 1건 / 주소 누락: 0건.
- 부산의 대략 범위(경도128.7~129.4, 위도34.9~35.5) 밖 좌표: 232건. 정확한 행정경계 판정이 아니므로 오류 확정 금지.
- 주소에서 정식 구·군을 추출하지 못한 데이터: 2,367건. 개인택시의 축약 주소(부산 동, 부산 수영 등)·타지역 주소 포함. 임의로 주소를 고치지 않았다.
- 위 조건 합집합 품질 검토 대상: 2,368건.
- 같은 좌표를 공유하는 그룹: 23,199개, 해당 행 123,817건. 같은 건물·주소 중심점·주소 축약 등 여러 원인이 있으므로 중복 가게로 삭제하면 안 된다.
- 상호에 택시가 포함된 데이터: 21,890건. 관광객 방문 가게 적합성은 별도 판단이 필요하다.

## GIS 사용

all_merchants_enriched.gpkg는 EPSG:4326 점 레이어, 전체 158,715건이다.
중복 CSV는 사용자 승인으로 삭제했다. 필요하면 GPKG에서 CSV로 내보낼 수 있다. 기존 원본 컬럼을 보존하고 조사 필드만 추가했다.

- travel_category: 식당 / 카페·디저트 / 쇼핑 / 관광대상외 업종 / 업종미매칭 / 분류검토
- purpose_status: classified / outside_scope / unmatched / review
- in_market: yes / no
- classification_evidence: 원천 업종 근거. 가게 연결 및 업종 정확도는 수동 검수 전이다.
- coordinate_status: valid는 세계 좌표 범위 및 대략 부산 범위 검사 통과라는 뜻이며 실제 가게 위치 확인을 의미하지 않는다.
- same_coordinate_count: 동일 원본 좌표의 행 수
- same_name_address_count: 동일 상호·주소의 행 수

검증: 158,715건 ID 유일, 모든 원본 필드 보존, 분류·지역 합계 일치, 시장 안·밖 합계 일치, 원본 SHA256 불변, GeoPackage 피처 수 일치.
추가 API 호출·신규 업종 매칭·폐업 여부 확인은 이번 조사에 포함하지 않았다. 기존 추천 데이터와 홈페이지 로직도 변경하지 않았다.
