# 통합 Place 전처리 참고자료

기준: 2026-10-23. 서비스 파일은 [../fin/places.csv](../fin/places.csv)이고 추천 API는 `load_places()`로 해당 파일을 사용합니다. 쇼핑·관광명소 입력도 통합돼 있습니다. 이전 ‘부분 통합·API 미전환’ 설명은 현재 상태가 아닙니다.

| 파일 | 역할 |
|---|---|
| `duration_rules.csv` | 유형별 기본시간·참고 범위·근거. 실측 평균 아님 |
| `place_sources.csv` | 장소 ID·원천·분류·유형·시장 안팎 근거 |
| `places_review.csv` | 필수 정보·분류·매칭 검토. 고객 리뷰 아님 |
| `tourism_coordinate_evidence.csv` | 선정 관광명소 좌표 근거 |
| `mvp_tourist_spots_review.csv` | 관광명소 권역·좌표 등 검토 |
| `summary.json` | 빌더 실행 시점 집계. 과거 호환 필드는 현재 배포 상태와 별개 |

카테고리는 **식당 / 카페·디저트 / 관광명소 / 쇼핑**의 4개입니다. 시장 안 가게는 본래 업종을 유지합니다. 미확보 금액은 빈칸이며 리뷰수·평점·이미지 컬럼은 서비스 CSV에서 제거했습니다. 기존 영업시간 원문은 보존하고, 요일별 시간표는 `../fin/place_opening_hours.csv`에 별도로 입력합니다. 결제 상태는 명부 근거와 미확인을 구분합니다.

재생성은 [장소 계약](../../../docs/PLACES_SCHEMA.md)의 QGIS 명령을 사용하고 쇼핑·관광명소 입력을 모두 지정합니다. 한쪽을 생략하면 부분 결과로 덮어쓸 수 있습니다. 로더는 캐시하므로 CSV 갱신 후 백엔드를 재시작해야 합니다.
