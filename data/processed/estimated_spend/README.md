# 예상지출 숫자 가격 기록과 누락 기록 분리

기준: 수작업으로 수집된 숫자 가격은 사용자 지시에 따라 정상 기록으로 취급합니다. 대표메뉴·출처·선정 기준 누락이나 공유 메뉴 여부로 분리하지 않습니다. 이전의 엄격한 근거 검수 판정은 이번 정제에서 제거했습니다.

| 파일 | 내용 |
|---|---|
| `data/raw/estimated_spend/merchant_spend_400_original.csv` | 원본 400곳. 입력 가격·상태·메뉴·출처와 하이퍼링크 실제주소 보존 |
| `merchant_spend_400_cleaned.csv` | 숫자 가격이 입력된 361곳 |
| `merchant_spend_400_price_review.csv` | 가격이 없거나 숫자가 아닌 기록. 분리 사유 포함 |

- 현재 분리 대상은 가격 누락 39곳이며, 비어 있지 않은 가격 중 문자가 섞인 기록은 0곳입니다.
- 쉼표 천 단위 표기와 소수 숫자도 숫자로 인정합니다. `12,000원`처럼 단위 문자가 포함되면 별도 분리합니다.
- 원래 금액·행 순서·장소 ID·원본 상태·담당자·메타데이터는 바꾸지 않습니다. `출처 URL 실제주소`에 Excel 하이퍼링크를 추출한 주소가 있습니다.
- 폐업 표시 3곳은 모두 가격이 비어 있어 분리 파일에 포함됩니다. 폐업 표시만으로 가격 유효성을 판단하지 않으며 서비스 가맹점 데이터도 삭제하지 않습니다.
- 숫자 기록 인정은 사용자가 정한 데이터 처리 기준이며 외부 출처 대조를 새로 수행한 것은 아닙니다. 숫자 가격은 아래 서비스 통합 절차로 `fin/places.csv`에 반영합니다.

원본 CSV에서 재실행:

```powershell
python scripts/clean_estimated_spend.py
```

## 새 조사 대상 39곳

`merchant_spend_39_new_survey.csv`는 가격 누락 39곳을 대체할 신규 조사 명부입니다. 기존 400곳의 ID와 상호·주소가 겹치는 장소를 제외하고 서비스 명부의 동백전 등재 식당·카페에서 추출했습니다. 동·업종 동일 후보를 먼저 배정하고, 부족하면 같은 업종의 다른 MVP 동, 같은 동의 다른 업종, 나머지 후보 순으로 배정했습니다.

- 최종 구성: 식당 23곳·카페·디저트 16곳, 남포동 14곳·광복동 15곳·부평동 10곳.
- 대청동 신규 후보는 없고, 카페는 ID가 다른 동일 상호·주소 1곳을 추가 제외하면서 16곳만 남았습니다. 따라서 기존 39곳의 동·업종 비율을 그대로 유지할 수 없습니다.
- 기존 기록 361곳에 이 명부를 합쳐 400곳으로 조사하면 식당 257곳·카페·디저트 143곳으로 바뀝니다. 원래 표본과 동일한 층화 비율로 해석하지 않습니다.
- 2026-10-26 웹 조사로 메뉴·가격·출처·확인일·검토 메모를 기록했습니다. 현재 상태는 아래 조사 결과를 따릅니다.
- 교체 대상 ID·상호·동·업종과 배정 사유를 함께 기록했습니다. 기존 361곳·누락39곳 조사 CSV는 유지하며, 서비스 통합은 아래 절차를 따릅니다.
- 시드: `20261026:spend-replacement39`. 재실행: `python scripts/sample_spend_replacements.py`. 조사 결과가 있는 파일은 덮어쓰지 않도록 차단합니다.


## 새 조사 대상 웹 조사 결과 (2026-10-26)

- 39곳 전부 상호·주소로 공개 자료를 검색했습니다. 외부 계정 로그인·유료 API·전화 문의는 사용하지 않았습니다.
- 18곳은 단품·1인 메뉴의 숫자 가격을 기록했습니다. 9곳은 메뉴 전체 금액만 확보하고 1인 금액은 보류했으며, 12곳은 적용할 메뉴 가격을 확보하지 못했습니다.
- 상태별로는 완료 18곳, 확인 필요 12곳, 정보 없음 9곳입니다. 가격 미확보 12곳 중 3곳은 폐업 표시·동명이점·업종 문제 등이 있어 확인 필요로 구분했습니다.
- `merchant_spend_39_research_review.csv`에 확인 필요·정보 없음 21곳을 모았습니다. 숫자 가격 18곳은 기존 조사 CSV에서 상태를 필터링하면 됩니다.
- 확인일은 웹 열람일이며 가격 시행일이나 현장 영업 확인일이 아닙니다. 출처가 과거 후기·메뉴 재가공 자료인 경우 메모에 구분했습니다.
- 카페051은 일반 패스오더 메뉴를 기록하고 100원 이벤트는 제외했습니다. 온도·주문채널 차이는 메모를 확인합니다.

- 공유 인원을 확인할 수 없는 고기·치킨·회 가격은 `원래 가격(원)`에만 기록하고 `1인 가격(원)`은 비워뒀습니다. 인원을 임의로 가정하지 않았습니다.
- 폐업 정보는 제3자 자료의 표시이며 현재 폐업을 확정한 것은 아닙니다. 상호·주소가 다른 자료의 가격도 바로 반영하지 않았습니다.
- 361곳 기존 숫자 가격 CSV는 유지합니다. 웹 조사 후 서비스 가격 통합은 아래와 같이 진행했습니다.


## 1차 서비스 가격 통합 (2026-10-26)

- `python scripts/merge_estimated_spend.py`로 기존 숫자 가격 361곳과 신규 조사 완료 가격 18곳을 정확한 장소 ID로 연결했습니다. 상호·카테고리 일치도 확인합니다.
- `data/processed/fin/places.csv`의 기존 `estimated_spend` 컬럼에 총 379곳의 가격을 반영했습니다. 1차 통합 당시 전체 783곳 중 나머지 404곳은 빈칸(NULL)이었습니다. 아래 추가 조사 후 현황으로 갱신했습니다.
- 장소 수·행 순서·나머지 모든 컬럼은 보존합니다. 새 조사 중 확인 필요·정보 없음 21곳의 메뉴 전체 금액은 반영하지 않습니다.
- 가격 출처·대표메뉴·확인일은 위 조사 CSV에서 장소 ID로 확인합니다. 기존 수작업 가격의 출처 재검증은 수행하지 않았습니다.
- 기존 가격과 충돌하거나 장소 ID·상호·카테고리가 맞지 않으면 저장 전에 중단합니다. 동일 입력으로 재실행해도 결과는 같습니다.
- `build_places.py`로 장소 명부를 새로 생성한 경우 가격 통합 명령을 다시 실행해야 합니다. 조사 ID가 새 명부에서 빠졌다면 해당 입력을 먼저 검토합니다.
- 이번 작업은 CSV 반영이며 홈페이지 가격 표시·배포는 별도입니다.


## 나머지 가격 조사 및 추가 반영 (2026-10-26)

### 범위와 결과

- 1차 통합 후 빈칸 404곳 중, 명세상 가격 제공 대상인 식당 355곳·카페/디저트 32곳, 총 387곳을 상호·주소로 웹 검색했습니다. 일부는 재검색 및 메뉴 페이지 직접 열람을 추가했습니다. 열람 실패도 있으며 모든 가게의 현장 가격을 확인했다는 뜻은 아닙니다.
- 쇼핑 10곳·관광명소 7곳은 현재 예상지출 제공 대상이 아니므로 빈칸을 유지했습니다. 무료로 간주한 것이 아닙니다.
- 추가 반영 59곳: 웹에 표시된 단품·1인 메뉴 가격 58곳 + 기존 수작업 가격 재사용 1곳. 기존 수작업 가격의 외부 재검증은 수행하지 않았습니다.
- 재사용 1곳은 원더풀꽈배기 자갈치점입니다. ID는 다르지만 공백을 제외한 상호·주소·카테고리·위경도가 모두 같은 기존 수작업 행의 1000원을 연결했습니다. 두 장소 ID 자체는 변경하거나 합치지 않았습니다.
- 전체 조사 결과는 완료 59곳·확인 필요 125곳·가격 미확보 203곳입니다. 확인 필요/가격 미확보는 서비스의 가격 값을 비워둡니다.
- 최종 `fin/places.csv`: 전체 783곳 중 가격 438곳(식당 301·카페/디저트 137), 빈칸 345곳(조사 대상 328 + 적용 대상 외 17).

### 파일

| 파일 | 역할 |
|---|---|
| `merchant_spend_remaining_survey.csv` | 387곳 전체 조사 명부. 메뉴·금액·출처 URL·열람일·판정·검색어·보류 이유 |
| `merchant_spend_remaining_review.csv` | 가격 반영을 보류한 328곳. 전체 명부에서 다시 추출할 수 있는 검토용 목록 |

- `1인 가격(원)`은 서비스에 반영한 금액만 기록합니다. 공유 메뉴·고기 단가·주소 불일치 등으로 보류한 금액은 `원래 가격(원)`에만 둘 수 있습니다. 다른 지점 가격은 확정하지 않습니다.
- 확인일은 2026-10-26 웹 열람/대조일입니다. 가격 시행일·현장 확인일·영업 보장일이 아닙니다. 웹 메뉴의 마지막 가격 갱신일이 미상인 경우도 있습니다.
- 메뉴 1개·1잔의 표시 가격이므로 실제 총 주문액이나 소비자 평균 지출을 뜻하지 않습니다. 점심특선 등 조건은 메모에 남겼습니다. 조건부 가격을 시간대별로 적용하는 기능은 별도입니다.
- 하삼동커피는 지점 패스오더 일반 메뉴 1800원을 사용했습니다. 다른 자료의 1500원~와 차이가 있어 주문 채널·시점 차이 가능성을 메모에 기록했습니다. 100원 이벤트는 제외했습니다.
- `조사 참고 URL`은 검색 참고자료이며 다른 지역의 동명 점포가 포함될 수 있습니다. 실제 가격 근거는 `출처 URL`, 적용 여부는 `상태`와 `1인 가격(원)`으로 확인합니다.
- 시장 상회의 업종 불일치, 상세 주소 누락, 폐업 관련 표시는 검토 사유로만 기록했습니다. 장소 삭제·업종 수정·좌표 변경은 하지 않았습니다. 페이지의 공통 ‘폐업신고’ 버튼은 폐업 근거로 사용하지 않았습니다.

### 서비스 파일 재반영

```powershell
python scripts/merge_estimated_spend.py
```

통합 스크립트는 기존 361곳, 신규 39곳 조사 중 완료 18곳, 나머지 조사 중 완료 59곳을 ID로 결합합니다. 재생성 시에도 조사 명부가 있으면 같은 금액을 재반영합니다. `build_places.py`를 실행한 뒤 위 명령을 실행하세요. 현행 장소 ID가 조사 명부와 달라지거나 기존 가격과 충돌하면 저장 전에 중단하므로 입력을 먼저 검토해야 합니다.

검증: 원래 379곳 가격 보존, 추가 59곳만 변경, 전체 장소 수·ID·순서·나머지 14개 컬럼 보존, 미확보 금액 NULL 유지, 통합 재실행 동일 결과, 백엔드 `load_places()` 로딩 확인. 웹사이트 표시·Render 배포는 이번 작업에 포함하지 않았습니다.
